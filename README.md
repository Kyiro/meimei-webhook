# the humble meimei webhook

<img align="right" src="./.github/assets/mm-avatar.png" height="150px" alt="cutout of meimei's face">

simple nushell script to post new meimei posts in a discord channel (using a webhook)

# configuration

`config.toml`
```toml
webhook_url = "https://discord.com/api/webhooks/x/y"
```

# requirements

- gallery-dl
- nushell
